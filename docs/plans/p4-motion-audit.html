FA motion audit

Review of the new app shell before the P4 deploy: Overview, Activity, Quick add, edit sheet and pull to refresh. Judged as a daily-use finance tool, so motion should be fast, quiet and only where it explains a change.

Date 11 Oct 2026Lens Emil Kowalski (primary), Jakub Krehel (secondary)Scope src/components/fa, src/pages/fa

Fixed before deploy

  • HighRefresh icon spun on every 30 s auto-refresh Background refreshes are invisible by design. The icon and the pull indicator now spin only when you ask for a refresh. Fixed.
  • HighCategory bars replayed from zero on every switch back to Overview Segment switching is frequent, so a replay each time becomes noise. Bars grow on the first load only; after that they move only when a value changes. Fixed.
  • High"All time" rendered about 2,100 animated rows Heavy on phones and makes every refresh expensive. Activity now shows 150 rows with a "Show more" button. Fixed.
  • MediumSegment switch took about 300 ms end to end Enter shortened to 150 ms with a smaller slide; exit is a plain 80 ms fade. Fixed.
  • MediumProgress bars animated width Switched to scaleX from the left edge, so only transform animates. Fixed.

Checked and fine

  • PassReduced motion App-wide MotionConfig reducedMotion="user", a CSS reduced-motion guard, and the spent total jumps straight to its value.
  • PassEasing and springs Custom ease-out curve throughout; the segment pill uses a spring with no bounce. No bare ease.
  • PassExits lighter than entries Rows enter with fade, 6 px rise and slight blur over 220 ms; deletes leave in 150 ms.
  • PassNew-row highlight Only transactions that are new since the last refresh get a 2 s tint; existing rows never animate on refresh.
  • PassPress feedback Add button 0.95, chips and pills 0.97 on press. No hover-scale on cards.

Left as is

  • LowSkeleton to content swaps instantly Happens once per visit and the data is what matters. Not worth a transition.
  • LowHighlight tint animates background colour A single small row for 2 s. Cheap enough; kept for clarity.
